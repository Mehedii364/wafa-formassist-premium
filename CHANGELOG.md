# Changelog

## [1.1.0] — 2026-11-17

### Security Hardening & Production Upgrade
- **Zero-Plaintext Extension IndexedDB Vault**: Upgraded extension storage (`DB_VERSION = 2`) to encrypt all personal profile snapshots with AES-GCM-256 + PBKDF2-SHA256 (600,000 iterations, random 16-byte salt, unique 12-byte IV) before persistence, automatically purging legacy plaintext `'snapshot'` entries. Unlocked keys remain ephemeral and non-extractable in memory with `chrome.alarms` inactivity auto-lock.
- **Fail-Closed Extension Message Router**: Enforced strict sender extension ID verification, trusted extension-page origin checks for privileged actions, runtime payload schema validation, tab-context binding, unlock brute-force throttling (5 attempts / 5 minutes), and action rate limiting.
- **Independent Sensitive-Field Exclusion**: Added dedicated shared and extension sensitive-field classifiers (`content/sensitive-fields.js` loaded first) blocking passwords, OTP/2FA, CAPTCHA, payment/bKash/Nagad/card/CVV, security tokens, recovery codes, and file inputs during both scanning and autofill execution with zero false positives on NID, Birth Reg, Passport, Post Code, Roll, Mobile, or Email.
- **PostgreSQL Persistence & Hardened Auth Backend**: Added Drizzle ORM + Cloud SQL PostgreSQL repository (`PostgresCloudStore`) with transactional row-locked optimistic vault conflict detection (`409`), 10-backup retention pruning, persistent `rate_limit_buckets`, `HttpOnly; SameSite=Lax` session cookies (no `sessionToken` in JSON), double-submit `X-CSRF-Token` enforcement, scrypt password hashing with anti-enumeration timing parity, idle/absolute session expiry, prior-session revocation, optional Firebase Google Sign-In session exchange, and strict CORS/security headers.
- **Form Engine, Custom Fields & Rollback Safety**: Preserved existing user-entered form values unless explicitly approved for overwrite, prevented auto-selection of fuzzy dropdown matches, added Custom Profile Fields CRUD, added automatic Pre-Restore Rollback Snapshot protection in Backup & Restore, hardened Chrome & Edge MV3 ZIP packaging with secret scanning, and removed deprecated form-role wording across code, fixtures, and documentation.
